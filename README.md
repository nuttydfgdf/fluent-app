# Fluent – ฝึกพูดอังกฤษให้คล่อง (สำหรับสาย IT)

แอปเว็บ (PWA) ฝึก **shadowing + ทบทวนแบบ spaced repetition (FSRS)** เน้นวลี/ประโยคที่ใช้จริงในงาน
ไม่มี backend ไม่มีค่าใช้จ่าย ข้อมูลเก็บในเบราว์เซอร์ของคุณ ใช้ได้ทั้งเว็บและมือถือ

## วิธีทำงาน (1 เซสชัน ~10-15 นาที)
1. **ทบทวน**: เห็นคำแปลไทย → พูดอังกฤษให้เร็วที่สุด ระบบวัด "เวลาก่อนเริ่มพูด" + "ความตรงของคำ" แล้วแนะนำเกรด (ลืม/ยาก/ได้/คล่อง) คุณแก้เองได้
2. **ของใหม่**: ฟัง+อ่าน → พูดตามโดยดูข้อความ → พูดตามโดยไม่ดูข้อความ → ทดสอบจากความหมาย
3. ตอบเร็วและถูกต่อเนื่อง = ห่างออกเป็นสัปดาห์/เดือน, ตอบไม่ได้ = กลับมาเร็ว
4. มีของค้างเยอะ ระบบจะหยุดเพิ่มของใหม่ให้อัตโนมัติ

## Deploy ฟรี (เลือกอย่างใดอย่างหนึ่ง)
**GitHub Pages**
1. สร้าง repo ใหม่ (public) แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไว้ที่ root
2. Settings → Pages → Source: `Deploy from a branch` → `main` / `(root)`
3. รอ 1-2 นาที จะได้ URL `https://<ชื่อคุณ>.github.io/<repo>/`

**Cloudflare Pages**: Create project → Direct Upload → ลากโฟลเดอร์นี้ไปวาง (ไม่ต้อง build)

## ติดตั้งบนมือถือ
- Android (Chrome): เมนู ⋮ → Add to Home screen / Install app
- iPhone (Safari): ปุ่มแชร์ → Add to Home Screen

## ข้อจำกัดที่ควรรู้
- **ฟังเสียง/ตรวจคำพูด** ใช้ Web Speech API ของเบราว์เซอร์ ทำงานดีที่สุดบน **Chrome/Edge (Android และเดสก์ท็อป)** ส่วน iPhone/Safari อาจใช้ไม่ได้หรือไม่เสถียร ให้ใช้โหมดเงียบ + 🎙 อัดเทียบเสียงแทน
- เสียงอ่านต้นฉบับเป็น TTS ของอุปกรณ์ (เลือกเสียงได้ในตั้งค่า) ไม่ใช่เจ้าของภาษาจริง
- ข้อมูลอยู่ในเครื่องเดียว ใช้ "ส่งออก/นำเข้า" ในตั้งค่าเพื่อสำรองหรือย้ายเครื่อง
- ต้องเปิดผ่าน https (หรือ localhost) ไมค์และ service worker ถึงจะทำงาน

## เพิ่มเนื้อหาด้วย AI
ตั้งค่า → "คัดลอกพรอมต์" → วางให้ AI สร้าง pack → วาง JSON กลับในแอปแล้วกด "นำเข้า pack"
หรือแก้ `content.js` โดยตรง (ต่อท้าย pack เท่านั้น อย่าสลับลำดับรายการเดิม เพราะ id อิงตำแหน่ง)

## ทดลองในเครื่อง
`python3 -m http.server 8000` แล้วเปิด http://localhost:8000
